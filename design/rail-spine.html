Spine, boxed

Each section (Local, Remote, Containers, Elevated) is its own rounded box with its colored spine inside. Click a tab to make it active. Click a section or group heading to collapse it.

Section box

One rounded box per section, tinted 5% with its color and a 1px edge at 16%. Elevated is a little stronger (8% / 26%) so root always stands out. No box for groups or tabs.

Spine

A 1.5px line in the section color runs down the box. Groups are hollow circles on it (filled when collapsed). Tabs branch off it, and the active tab's branch turns the accent color.

Tabs

One line: number, program, short path, status dot. Only the active tab gets a second line with details (process, memory, git branch, time).

Collapsed section

Collapsing a section keeps its status dots on the header, so you can still see a failure or a running job without opening it.
